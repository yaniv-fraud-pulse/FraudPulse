SUMMARY
FraudPulse connects to transaction data from Shopify, Stripe, or Adyen and recommends rules and actions that reduce chargebacks and friendly fraud. Pricing is usage- or plan-based with no per-seat surprises on the published plans below.

FREE TRIAL
- 14-day free trial on every plan
- No credit card required
- Full access to plan features during the trial

PLAN: PAY AS YOU GO
- Price: $0.01 per transaction
- Volume: Up to 20,000 transactions / month
- Best for: Growing merchants; no monthly subscription
- Included: AI advisor recommendations, chargeback ratio monitoring, 2 user seats
- Not included: Payment enrichment, custom rules engine, API access, dedicated account manager

PLAN: PROFESSIONAL (most popular)
- Monthly: $199 / month
- Annual: $159 / month billed annually (~20% savings, about $480 / year)
- Volume: Up to 50,000 transactions / month
- Best for: Established merchants needing AI insights and fuller platform access
- Included: AI advisor recommendations, 1-hour monthly fraud advisor meeting, real-time fraud scoring, chargeback ratio monitoring, 5 user seats, custom rules engine (up to 10 rules), full API access (Shopify, Stripe, Adyen)
- Not included: Dedicated account manager

PLAN: ENTERPRISE
- Price: Custom
- Volume: Unlimited transactions
- Best for: High-volume merchants and enterprises needing custom solutions and SLAs
- Included: AI advisor recommendations, real-time fraud scoring, chargeback ratio monitoring, all alert channels + custom, custom analytics & reporting, unlimited user seats, custom rules engine + ML models, full API access + webhooks, dedicated account manager + SLA

TRANSACTION VOLUME
A transaction is any payment event FraudPulse ingests (authorisations, captures, refunds, chargebacks). Only current-period events count toward the monthly limit. Historical backfills for analysis do not consume plan capacity.

OVERAGE AND PLAN CHANGES
- Upgrade or downgrade from account settings
- Upgrades immediate and prorated; downgrades at next billing period
- Notifications at ~80% and 100% of monthly limit
- Service not cut off by default; overages bill per-transaction until upgrade (optional hard cap in settings)

INTEGRATIONS
Shopify, Stripe, and Adyen. Professional and Enterprise add fuller API access and webhooks; Enterprise can include custom integrations.
